# 🧠 Bazai Notebooks

> A collection of hands-on AI, Generative AI, LLM, Agentic AI, Cloud, and Machine Learning notebooks by **Bazai Tech**.

Welcome to **Bazai Notebooks** — an evolving collection of practical experiments, tutorials, prototypes, and production-oriented implementations covering the rapidly evolving AI ecosystem.
